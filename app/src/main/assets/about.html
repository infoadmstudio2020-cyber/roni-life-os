About NativeRuntime

A six layer Android runtime that gives a WebView application a fully native shell.

Layer contract

  • native-runtime-contracts — shared interfaces
  • native-runtime-engine — lifecycle orchestration
  • native-runtime-ui — native component shell
  • native-runtime-sdk — public consumer API
  • native-web-bridge-sdk — JS to native RPC
  • native-*-engine — storage, network, security

Consumer contract

Extend NativeRuntimeActivity, return a NativeRuntimeUIConfig from onConfigureUI, then supply any web content source. The shell is built once and never recreated when the source changes.
